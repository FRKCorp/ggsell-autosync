## 1. Что нужно

- **Сервер (VPS):** Ubuntu 22.04 или 24.04, от 2 ГБ памяти и 20 ГБ диска.
- **Домен или поддомен**, A-запись которого указывает на IP сервера. На него GGSell присылает уведомления о продажах, HTTPS настраивается сам.
- **GGSell:** аккаунт продавца, API-ключ (API v2), а также ID продавца и ключ старого API (V1). Всё — в кабинете продавца, раздел API.
- **FazerCards:** API-ключ аккаунта с **активной подпиской** и **пополненным балансом** — с него оплачиваются заказы покупателей.
- **Telegram-бот:** токен от @BotFather и ваш chat_id (покажет @userinfobot). После создания бота нажмите в нём Start.
- **Прокси для Telegram** — только если сервер в России (там Telegram заблокирован): HTTP-прокси вне РФ.

## 2. Установка

### 2.1. Docker

```bash
apt-get update && apt-get install -y ca-certificates curl git
install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo $VERSION_CODENAME) stable" > /etc/apt/sources.list.d/docker.list
apt-get update && apt-get install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin
docker compose version
```

### 2.2. Код

Репозиторий закрытый, поэтому сервер получает к нему доступ по ключу «только для чтения» (deploy key):

```bash
ssh-keygen -t ed25519 -N "" -C "deploy@$(hostname)" -f ~/.ssh/github_deploy
cat ~/.ssh/github_deploy.pub
```

Выведенную строку добавьте в GitHub: репозиторий → Settings → Deploy keys → Add deploy key, без галочки «Allow write access». Затем:

```bash
cat >> ~/.ssh/config <<'EOF'
Host github.com
    IdentityFile ~/.ssh/github_deploy
    IdentitiesOnly yes
EOF
git clone git@github.com:FRKCorp/ggsell-autosync.git /root/ggsell-autosync
cd /root/ggsell-autosync
```

### 2.3. Файл настроек и база данных

```bash
cp .env.example .env
sed -i "s|^POSTGRES_PASSWORD=.*|POSTGRES_PASSWORD=$(openssl rand -hex 24)|" .env
docker compose build
docker compose up -d db backup
docker compose run --rm app alembic upgrade head
```

Пароль базы данных сгенерирован автоматически. **Не меняйте его потом**, иначе система потеряет доступ к уже созданной базе.

## 3. Заполнение настроек (.env)

Все ключи и токены хранятся **только** в файле `.env` на сервере, в репозиторий он не попадает. Откройте его:

```bash
nano .env
```

Заполните строки под пометкой **«ЗАПОЛНИТЕ»**. Сохранить — Ctrl+O, Enter, выйти — Ctrl+X.

| Строка | Что вписать |
|---|---|
| `DOMAIN` | Домен без `https://`, например `shop.example.ru` |
| `GGSELL_API_KEY` | API-ключ продавца GGSell (API v2) |
| `GGSELL_V1_SELLER_ID` | ID продавца GGSell (число) |
| `GGSELL_V1_API_KEY` | Ключ старого API GGSell (V1) — это другой ключ, не тот, что выше |
| `FAZERCARDS_API_KEY` | API-ключ FazerCards |
| `ADMIN_TELEGRAM_BOT_TOKEN` | Токен бота от @BotFather (вида `1234567890:AAH…`) |
| `ADMIN_TELEGRAM_CHAT_ID` | Ваш chat_id. Несколько администраторов — через запятую |
| `TELEGRAM_PROXY` | Только если сервер в России: `http://логин:пароль@IP:порт`. Иначе оставить пустым |

Остальное в файле — начальные значения наценки, курса и расписания, их можно не трогать.

**Проверка:**

```bash
docker compose run --rm app python scripts/check_env.py
```

Скрипт проверит, что всё заполнено, и попробует подключиться ко всем сервисам: БД, FazerCards (подписка и баланс), GGSell (оба ключа), Telegram (пришлёт в бота тестовое сообщение) и домен (указывает ли он на этот сервер). Сами ключи он не печатает. Исправляйте `.env`, пока везде не будет ✅.

## 4. Запуск и проверка

**Каталог товаров** — импорт из FazerCards (несколько минут):

```bash
docker compose run --rm app python scripts/bulk_import_topups.py
docker compose run --rm app python scripts/bulk_import_giftcards.py
docker compose run --rm app python scripts/import_special.py
```

**Запуск всех сервисов:**

```bash
docker compose up -d
docker compose ps
curl -s https://ВАШ_ДОМЕН/health
```

- `{"ok":true}` означает, что сервер работает, а HTTPS-сертификат получен. Если ответа нет сразу, подождите минуту и посмотрите `docker compose logs caddy`.
- Сразу после запуска начнётся первая синхронизация цен (около 2 минут), дальше — каждые 12 часов.
- В Telegram-боте нажмите **📊 Статус**: там должны быть курс, наценка и баланс FazerCards.

**Фаервол** — закрыть всё, кроме SSH, HTTP и HTTPS:

```bash
sh ops/firewall.sh
```

Если SSH на нестандартном порту: `SSH_PORT=2200 sh ops/firewall.sh`.

## 5. Залив товаров на GGSell

Все лоты создаются **черновиками** с временной обложкой. Добавить свои обложки и опубликовать — в кабинете GGSell. Система после этого меняет у лотов только цену; тексты и обложки она не трогает.

**Сначала один пробный лот** — подарочная карта Google Play (Индия), около 12 ₽:

```bash
docker compose exec app python scripts/upload_offers.py --only giftcard:google_play_in:10_inr
```

Опубликуйте его в кабинете GGSell, купите и убедитесь, что:
- код пришёл в чат заказа;
- в боте заказ отмечен «✅ выдан».

После этого снимите лот с публикации.

**Весь каталог:**

```bash
docker compose exec app python scripts/upload_offers.py --dry-run     # проверка, без GGSell
docker compose exec app python scripts/upload_offers.py               # залив, около часа
```

- **Повторный запуск безопасен:** уже созданные лоты не дублируются, а недосозданные опции досоздаются. Если в конце есть ошибки, запустите команду ещё раз.
- **Лоты без категории.** Товары, для которых на GGSell нет подходящей категории (например, Razer Gold), не заливаются.

## 6. Как устроены цены

```
цена лота = цена FazerCards ($) × курс × (1 + наценка) ÷ (1 − комиссия GGSell)
```

- **Курс** — курс ЦБ РФ плюс надбавка (по умолчанию 5%). Обновляется перед каждой синхронизацией цен и виден в панели бота.
- **Наценка «чистая».** Комиссия GGSell (своя у каждой категории, обычно 2–6%, плюс 2.7% за приём оплаты) удерживается из цены лота. Поэтому система закладывает её в цену сверху: после удержания вы получаете ровно себестоимость + наценку. Из-за этого цена на витрине на 5–10% выше, чем «курс × (1 + наценка)».
- **Округление** — вверх до целого рубля. У пополнения Steam и Telegram Stars цена указана за единицу (1 ₽ Steam, 1 звезда), там до копейки.
- **Обновление на витрине.** Раз в 12 часов цена обновляется, если расчётная отличается от текущей больше чем на 1%. После смены наценки в боте обновляются все изменившиеся цены сразу.
- **Защита от убытка:**
  - если текущая цена перестала давать минимальную маржу (3%), она поднимается сразу, и в бот приходит алерт;
  - перед каждой закупкой цена у FazerCards перепроверяется: если она выросла больше чем на 5%, заказ уходит на ручной разбор.
- **Цену, изменённую вручную в кабинете GGSell, система вернёт к расчётной.** Чтобы задать цену отдельного лота, используйте **индивидуальную наценку** в боте.

## 7. Telegram-бот

Бот отвечает только chat_id из `.env`.

| Кнопка / команда | Что делает |
|---|---|
| 📊 **Статус** | Прайсер вкл/выкл, курс и наценка, время последнего обновления цен, лоты по статусам, заказы за сутки, сколько требует внимания, баланс FazerCards |
| 🤖 **Авто-прайсер** | Включить/выключить прайсер, глобальная наценка, надбавка к курсу ЦБ, **наценка отдельного лота** (поиск по id или названию), «Обновить цены СЕЙЧАС» |
| 🧾 **Заказы** | Последние заказы и их статусы |
| ⚠️ **Ручной разбор** | Заказы, требующие внимания, с причиной и данными покупателя |
| `/lot <id или название>` | Карточка лота: цена, наценка, комиссия |
| `/pause <id>` / `/activate <id>` | Снять лот с публикации / опубликовать |
| `/sync` | Обновить цены сейчас |

**После смены наценки** цены на GGSell пересчитываются сами за 2–3 минуты, итог приходит сообщением.

**Ручной разбор заказа:**
1. Придёт алерт с причиной: например, «FazerCards отказал — недостаточно средств».
2. **Ответьте (reply) на алерт или на карточку в «Ручном разборе»** — бот покажет текст и спросит подтверждение. После «📨 Отправить» сообщение уйдёт покупателю в чат заказа.
3. Выдайте товар вручную или верните деньги в кабинете GGSell (заказ → «Возврат средств»).
4. Нажмите **«✅ Выдан вручную — закрыть»**, чтобы заказ ушёл из списка.

**Алерты, которые присылает система:**
- заказы на ручном разборе;
- товар пропал у поставщика или закончился (и снова появился);
- цены подняты из-за просевшей маржи;
- сбой обновления цен или связи с FazerCards (например, истекла подписка);
- сторож: сервис не отвечает, нет связи бота с Telegram, нет свежего бэкапа, заканчивается место на диске, сервис перезапустился. Об исправлении проблемы тоже приходит сообщение «✅ Восстановлено».

## 8. Обслуживание

### Обновление кода

```bash
git pull --ff-only
docker compose build app scheduler bot
docker compose run --rm app alembic upgrade head
docker compose up -d
```

Миграции БД (`alembic upgrade head`) — **до** запуска сервисов.

### После изменения `.env`

```bash
docker compose up -d --force-recreate
```

Обычный `restart` новые настройки не подхватывает.

### Логи

```bash
docker compose logs --since 1h scheduler    # цены, заказы, сторож
docker compose logs --since 1h app          # уведомления GGSell о продажах
docker compose logs --since 1h bot
docker compose logs backup
```

Размер логов ограничен, старые удаляются сами.

### Бэкапы

- **Расписание.** Каждую ночь в 03:30 МСК делается копия базы в папку `backups/`, хранятся 7 последних.
- **Копии бэкапов** стоит иногда забирать к себе: если сервер пропадёт целиком, бэкапы пропадут вместе с ним. Например, с компьютера: `scp -r root@СЕРВЕР:/root/ggsell-autosync/backups ./`.

**Проверить, что бэкап восстанавливается** (рабочую базу не трогает):

```bash
docker compose exec -T backup sh /ops/restore_check.sh
```

**Восстановить базу из бэкапа** (заменит текущие данные):

```bash
docker compose stop app scheduler bot
docker compose exec -T backup sh -c 'pg_restore --clean --if-exists --no-owner -d "$PGDATABASE" /backups/ИМЯ_ФАЙЛА.dump'
docker compose up -d
```

### Внешний мониторинг

Сторож внутри системы присылает алерты, но не сможет сообщить, если **сервер упадёт целиком**. Для этого добавьте адрес `https://ВАШ_ДОМЕН/health/full` в бесплатный [UptimeRobot](https://uptimerobot.com):
1. New Monitor → тип HTTP(s) → этот адрес, интервал 5 минут.
2. Alert Contacts — e-mail или Telegram.

Адрес отвечает 200, когда всё в порядке, и 503 — если недоступна база или остановился планировщик.

## 9. Частые ситуации

| Что случилось | Что делать |
|---|---|
| Алерт «FazerCards: цены не обновились…», ошибка 403 | Истекла подписка FazerCards — продлите в кабинете FZ |
| Заказ на разборе: «Insufficient balance» | Пополните баланс FazerCards, затем выдайте товар вручную или верните деньги |
| Заказ на разборе: «покупатель не выбрал сервер» / «данные не подходят» | Напишите покупателю через бот (reply), уточните данные, выдайте вручную |
| Заказ на разборе: «логин Steam нельзя пополнить» | Попросите у покупателя правильный логин Steam (именно логин для входа, не никнейм) |
| Заказ на разборе: «сбой связи при покупке Telegram — заказ МОГ пройти» | Проверьте в кабинете FazerCards, прошёл ли заказ, и только потом выдавайте вручную или возвращайте деньги |
| Алерт «Пропало у FazerCards» | Товар убран у поставщика. Снимите лот с публикации: `/pause <id>` |
| Алерт «бот не связывался с Telegram» | Если используется прокси — проверьте его срок. Затем `docker compose up -d --force-recreate bot` |
| Сайт не отвечает | `docker compose ps`, `docker compose logs --since 1h app`, `docker compose up -d` |
| Заканчивается место на диске | `df -h`, `docker system prune` (удаляет старые образы) |
| Нужно поменять ключ или токен | Исправьте `.env`, затем `docker compose up -d --force-recreate` |
