# Roadmap — от текущего состояния до сдачи проекта клиенту

Чек-лист, по которому сверяемся после каждого шага. Пункт закрывается (`[x]`) только когда выполнен его **критерий готовности** — не раньше. Рядом с закрытым пунктом — дата и, если есть, коммит.

Обозначения: **[клиент]** — нужно решение/действие заказчика; **[прод]** — действие на боевом сервере.

Порядок этапов = порядок выполнения. Критический путь: 1 → 2 → 3 → 5 → 8 → 9. Этапы 0, 1, 5, 6 не зависят от решений клиента и делаются, пока ждём этап 2.
